# Production gates

1. Independently compare saved section renders and actual source envelopes to concept sheets. Record exact uncovered extent and deliberate reference inconsistencies; snapshot before further map writes. Define section versus whole-tile completion explicitly.
2. Correct Chain Crossing/Sluice art placement, material repetition, local-light readability and any exposed source gaps. Show an updated arrangement before live writes. Verify source mesh/collision/transform retention, footprint coverage, protected routes and actual player-camera views.
3. Pump+Cistern: source-fitted area concept + all new model sheets, with explicit reuse from the 88-piece kit. Complete inventory before modeling; keep shallow water at source depth.
4. Generate new models headless with shared reusable tools; build packed instanced Blender library/diorama and FBXs. Fresh saved-file geometry/bounds/material audit.
5. Import into an owned Unreal namespace; actual centimetre bounds/slots, no unintended collision. Complete the selected relevant tile including connective source surfaces. Review kit + diorama maps and clear coverage audit.
6. Actual Unreal/PIE player-camera observations at all identified routes/rooms, focused Toolbox automation and final saved-state audit. Record remaining gameplay mismatch and any topology limitation honestly.

Original tile rollback remains byte-for-byte backups with editor closed, preserving later unrelated edits. A new pre-correction checkpoint supplements but never overwrites the original production baseline. No reset/stage/commit/push.
