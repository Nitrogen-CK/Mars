Coordinates are **plan metres**, converted by `(x-70,y-55,z)*100` (`build_warrens.py:1536`); sizes are full extents. Existing floor heights govern. Proposed placements require Phase 1/2 measurement, not assumed collision/camera fit.

## Shared measurable contracts

Keep the 2.0 × 2.2 m PK cargo opening, 2.5 m spiral, six optional crawls and both pack-compatible ladders. Treat narrow corridors/ports as intentionally single file and add **2.4 m clear-width passing bays**, initially **2.4 × 2.4 m** for staging/turning, near PK east, both ladder ends, scout gate reunions and the Grotto junctions. Current pack width is 1.16 m and a chef capsule diameter is 0.78 m before clearance, so a 1.8 m lane is not a defensible passing promise (`Mars_Item_Sandbox.as:41`; player asset radius 39 cm). These are candidate dimensions to test with actual loaded bodies; enlarge a bay locally if necessary rather than widening every hall. Both ends must reveal a single-file constraint, and its waiting position must lie off the through-route.

Reserve ladder mount/dismount volumes, separate waiting pads and retrieval surfaces. Show landing/exit before every optional drop and provide a bounded recovery floor; no essential cargo over cracks. Preserve narrow passages, kitchen roof and sealed shell.

Keep pickups outside grips, doors, station cameras and other bodies; start with 0.6 m between rest centres, then measure meshes. Dressing defaults NoCollision. Structural/support collision or changed cover requires Phase 2 checks.

## Presentation asset contract

Use a small set of matte limestone, bone, soot-dark timber, iron/copper and mineral/brine surfaces. Material values must retain the project's ultra-low-poly, flat-shaded graphic style. Do not import a realistic gore or ornate photoreal pack. Phase 1 records actual existing mesh/material/audio object paths and licenses/source for any newly supplied audio. Missing assets get exact briefs: e.g. a sparse 20–40 second root-creak loop with silence, or a one-shot muted iron bell; they do not justify coding an audio system.

Ambient sound uses native positional level audio actors with attenuation, placed through the builder's existing owned-actor lifecycle. Verify the installed Unreal Python surface before implementing that small emission step. Bellkeeper one-shots use the established `Gameplay::SpawnSoundAttached` pattern, attached to owned visual components; stop/destroy owned loops on teardown. No timer-based AI events, audio middleware integration or hearing changes.
